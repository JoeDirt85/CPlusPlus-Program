#Summarize the project and what problem it was solving.
For this project, I was tasked with creating a program that would opena and read a .txt file, and would be able to count the frequency that an item was listed. 
To do this, the program would open and read the file, then go through each line of the file and add to the count. It would then store and backup the data before closing the file. With the count data, the program would then allow for user input to search for the frequnecy of a specific item, all items or display a histogram of the items.
